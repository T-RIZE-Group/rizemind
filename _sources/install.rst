=============
Installation
=============

This package is built on top of `Flower Framework <https://flower.ai/>`_.

It's highly suggested to get familiar with their framework prior to working with rizemind.

Installing with pip
====================

.. code-block:: bash

    pip install rizemind

Installing with uv
==================

.. code-block:: bash

    uv add rizemind

Next steps
==========

Choose :doc:`a quickstart <quickstarts/index>` or read
:doc:`Integrating with Flower <how-tos/flower-integration>`.

For Arc support, follow :doc:`the Arc guide <quickstarts/arc-mainnet>` and its
supported-release instructions. A package installation command alone does not
establish that the installed release contains the Arc example or registrations.
